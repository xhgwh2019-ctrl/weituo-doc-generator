# 一次性委托文件生成器

律师新收一个委托，只填一次表单，一键生成一个案件文件夹：**6 份独立文档**（签名处留白手写，直接打印）+ **1 份合一版**（无封面，每份另起一页、奇数页起始，双面打印即出 6 份独立文件）。

## 含哪 6 份

1. 法律事务聘请律师合同
2. 接待笔录
3. 当事人诉讼风险提示告知书
4. 授权委托书
5. 账户信息确认书（法院退费账号）
6. 送达地址确认书

模板在 `templates/`（已由当前文件夹示例文件转换，带 `{{占位符}}`），原示例文件保留在根目录备查。

## 启动

```bash
pip install -r requirements.txt
python3 app.py
```

- macOS 双击运行：`python3 app.py`
- 打包成单个 App/EXE（发给同事不用装 Python）：
  ```bash
  pip install pyinstaller
  pyinstaller --windowed --name 委托文件生成器 app.py
  ```

## 每次新案件要填什么（表单）

**必填（9项）：**
- 委托人姓名（多人用顿号：`叶建义、叶建海`）
- 身份证号（多人用空格/顿号分隔）
- 送达地址/住址
- 联系电话
- 对方当事人（如：`王艳萍`）
- 案由（如：`土地承包经营权转让合同`，不用写“纠纷”二字，程序自动加）
- 代理费（数字，如 `6000`，大写自动生成 `陆仟元整`）
- 银行账号、开户行（精确到支行，个人须一类账户）

**选填（有默认值，可空）：**
- 案号（立案前可空，后补）、合同编号（空=自动）、法院（默认大厂法院）、
  有效期至（默认“一审终结之日止”）、其他费用、收费/支付方式、
  户名（默认同委托人，一键同步）、落款日期（**自动为今天**，可改）

## 固定信息（只填一次）

点应用里的「固定信息设置」，保存在 `config.json`：
律所 `河北禄存律师事务所`、律师 `高卫华`、律师身份证/电话/送达地址、
接待地点、默认法院、收费标准 `冀律协2016第7号` 等。改一次以后一直用。

## 生成结果

`输出/委托人与对方案由纠纷_年-月-日/` 文件夹：
- `1~6_*.docx`：6 份独立文档（签名处留白手写，可直接分别打印）
- `0_合一版_6份齐全_*.docx`：合一版（无封面，每份另起一页、奇数页起始，双面打印即出 6 份）

## Windows 版（给其他电脑用）

### 方法一：免安装版 / 安装包（推荐，需先构建一次）

Mac 不能直接编译 Windows 程序，提供两种构建方式：

**A. 全自动（推荐）：** 把本项目推到 GitHub，Actions 会自动编译。

```bash
cd "/Users/gaoweihua/项目/一次性委托文件生成器"
 gh repo create 委托文件生成器 --public --source=. --push  # 需先装 gh 并登录
 # 或手动：GitHub 新建仓库 → git remote add origin <地址> → git push -u origin master
 git tag v1.0.0 && git push --tags   # 打标签触发构建
```

之后在 GitHub 仓库页 → Actions → 下载 `windows-portable`（免安装版 zip）
或 `windows-installer`（安装包 exe）。也可以点右上角 `...` 手动 Run workflow。

**B. 在 Windows 电脑上本地构建：** 把整个文件夹拷过去，双击 `build_windows.bat`，
得到 `dist\委托文件生成器\`（直接可用）；再用 Inno Setup 打开 `installer.iss` 编译即得安装包。

### 方法二：装 Python 直接跑（不懂打包时最省事）

1. Windows 上安装 Python 3.10+（官网 python.org，**勾选 Add python.exe to PATH**）
2. 把本文件夹拷过去，双击 `启动委托生成器.bat`
3. 首次自动装依赖，之后打开即用（config.json / 输出 与 Mac 通用）

## 目录结构

```

├── app.py              # 图形界面（tkinter，双击运行）
├── generator.py        # 占位符替换 + 合并逻辑
├── build_templates.py  # 示例文件 → templates 占位符模板（已运行过，一般不用再跑）
├── config.json         # 固定信息
├── templates/01~06_*.docx
├── 输出/               # 生成文件
└── 原始模板/            # 原稿示例文件（备查，01 号模板的底版也在此）
```
